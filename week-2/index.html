2.1Adding and multiplying functions

Combining functions
Two functions can be added, subtracted, multiplied or divided at every input they share.(f + g)(x) = f(x) + g(x)(fg)(x) = f(x)g(x)and the same for the difference, the quotient, and a constant times a function.
Where it is defined
Only where both originals are. For a quotient, also nowhere that g(x) = 0.
  1. Work out each function separately at the input. Two numbers, not one expression.
  2. Combine those two values with the operation.
  3. Intersect the domains. The combination exists only where both originals do.
  4. For a quotient, exclude anything that makes the bottom zero. Even where the top is perfectly well behaved.
  5. Bracket the second function before you subtract it. −(x2 + 3x) = −x2 − 3x. Both signs change.
f(x) = 3x − 1 and g(x) = x2 + 3x
  1. (f − g)(x) = 3x − 1 − (x2 + 3x)
    Bracket g before subtracting.
  2. = −x2 − 1
    The 3x cancels.
  3. (fg)(x) = 3x − 1x2 + 3x
    No cancelling: nothing is a common factor.
  4. undefined at x = 0 and x = −3
    Because x2 + 3x = x(x + 3) is zero there.
The one you will use all year
P(q) = R(q) − C(q)Profit is revenue minus cost, which is a subtraction of two functions and nothing more. Cost itself is usually a sum: a fixed part plus a variable part.
  • Watch out
  • Subtracting without brackets. It changes the sign of every term after the first.
  • Cancelling across a plus. 3x − 1x2 + 3x does not simplify.
  • Forgetting that the combination inherits both domains, not just the more generous one.

2.2Reading a graph

Not started

Learn it on Khan AcademyVideo Both intercepts · x-intercepts and y-interceptsVideo Intercepts of a parabola · Interpret a quadratic graphArticle Intercepts of lines review (x-intercepts and y-intercepts)Practise it on Khan AcademyExercise From the formula · Intercepts from an equationExercise Intercepts from a graph
Intercepts
The y-intercept is the value at zero, f(0). There is at most one, because a function gives one output per input. An x-intercept, or a zero, is any value where f(x) = 0. There may be several, or none.
  1. For the y-intercept, put x = 0. One substitution, no solving.
  2. For the x-intercepts, solve f(x) = 0. This is the step that is actual work.
  3. Plot the intercepts first. They are the two easiest points on any curve.
  4. Add enough further points to see the shape. For a line, two points are the whole story.
  5. Read the intercepts back into the question. A y-intercept is usually a fixed cost or a starting value. An x-intercept is usually a break-even point or the moment something runs out.
y = 2x + 3
  1. y-intercept: y = 2(0) + 3 = 3
    The curve crosses the vertical axis at 3.
  2. x-intercept: 2x + 3 = 0
    Set the output to zero and solve.
  3. x = −32
    One crossing, because a line has at most one.
A vertical line is not a function
x = 3 is a perfectly good line and has no y-intercept to speak of. It fails the vertical line test, so it is not the graph of a function of x.
  • Watch out
  • Solving f(x) = 0 and reporting the output. The answer is the input.
  • Assuming there is one x-intercept. A parabola has two, one, or none.
  • Reading an intercept off a sketch instead of solving for it.

2.3Composition of functions

Not started

Learn it on Khan AcademyVideo What a composite is · Composing functionsVideo At a number · Evaluating composite functionsArticle The definition · Intro to composing functionsPractise it on Khan AcademyExercise At a number · Evaluate composite functionsExercise Building the formula · Find composite functions
Composition
(f ∘ g)(x) = f(g(x))Do g first, then put its output into f. The circle is read right to left, which is the single most common thing to get wrong.
Where it is defined
x has to be something g accepts, and g(x) has to be something f accepts. Both conditions, not either.
  1. Evaluate the inner function at the input. One number out.
  2. Put that output into the outer function. That is the whole procedure for a number.
  3. For a formula, substitute the entire inner expression. Every x in the outer function becomes the whole of g(x), brackets included.
  4. Check the order. f ∘ g is almost never g ∘ f. One number settles it.
  5. For the domain, take what g accepts, then remove anything whose output f refuses.
f(x) = 2x + 1 and g(x) = x2 − 3
  1. (g ∘ f)(4): f(4) = 9
    Inner function first.
  2. g(9) = 81 − 3 = 78
    Its output is the input to the outer one.
  3. (f ∘ g)(x) = 2(x2 − 3) + 1
    Symbolically now: the whole of g goes in, in brackets.
  4. = 2x2 − 5
    Expand afterwards.
Why it turns up
Advertising spend gives visitors, visitors give revenue. The question asks revenue from advertising spend. The number of visitors is real, and the question is not about it.
  • Watch out
  • Reading f ∘ g left to right. The inner function is the one on the right.
  • Substituting without brackets, so only part of the inner expression gets squared or multiplied.
  • Assuming the domain is just what g accepts. The middle value has to be legal too.

2.4Inverses, and when one exists

Not started

Learn it on Khan AcademyVideo What an inverse is · Intro to inverse functionsVideo When one exists · Invertible functionsArticle One-to-one, written out · Intro to invertible functionsPractise it on Khan AcademyExercise Spotting when there is no inverse · Determine if a function is invertibleExercise Reading an inverse off a graph · Inverse functions: graphs and tables
Inverse function
For a one-to-one function f, its inverse f−1 sends every output back to the input it came from.f−1(f(x)) = xf(f−1(x)) = x
One-to-one
Different inputs always give different outputs. No output is ever produced twice. This is the whole condition for an inverse to exist.
Domain and range swap
The range of f is the domain of f−1, and the domain of f is the range of f−1.
  1. To test two functions, compose them both ways.
  2. Work out f(g(x)) and g(f(x)). Both, not one.
  3. If both come back to x, they are inverses. If either does not, they are not.
  4. To decide whether an inverse exists at all, use the horizontal line test. A horizontal line may cross the graph at most once. Twice means two inputs share an output, so there is no way back.
  5. A function that only ever rises, or only ever falls, passes. Strictly increasing or strictly decreasing is enough to be one-to-one.
  6. The graph of the inverse is the reflection in the line y = x.
Are f(x) = 2x − 1 and g(x) = x + 12 inverses?
  1. f(g(x)) = 2(x + 12) − 1
    Compose one way.
  2. = x + 1 − 1 = x
    Back to x.
  3. g(f(x)) = (2x − 1) + 12
    Now the other way.
  4. = x
    Both directions return x, so they are inverses.
  • Watch out
  • Reading f−1 as a reciprocal. It is not 1f(x).
  • Composing one way only. One direction can work by accident.
  • Assuming every function has an inverse. f(x) = x2 does not, until you restrict it.

2.5Finding an inverse

Not started

Learn it on Khan AcademyVideo Finding one, step by step · Finding inverse functions: linearVideo Checking it · Verifying inverse functions by compositionArticle The method, written out · Intro to inverse functionsPractise it on Khan AcademyExercise Finding one · Find inverses of linear functionsExercise Checking by composition · Verify inverse functions
  1. Check the function is one-to-one. If it is not, there is nothing to find yet.
  2. Write y = f(x).
  3. Solve for x in terms of y. This is the only step that is real work.
  4. Interchange x and y. The input goes back to being called x.
  5. Write the result as the inverse. y = f−1(x)
  6. Check by composing both ways. You should get x back each time. This catches almost every slip.
f(x) = 3x + 4
  1. y = 3x + 4
    Start from the definition.
  2. x = y − 43
    Solve for x.
  3. f−1(x) = x − 43
    Swap the names.
  4. f−1(f(x)) = (3x + 4) − 43 = x
    The check. It returns x, so it is right.
When there is no inverse yet
Restrict the domain until the function is one-to-one. f(x) = (x − 1)2 has no inverse over all the reals, because it repeats every output. Keep only x ≥ 1 and it has one.
The linear case, worth knowing by sight
f(x) = ax + b⇒f−1(x) = x − ba
What an inverse is for
To solve f(x) = k, apply the inverse to both sides. That is the job it does.
  • Watch out
  • Swapping the names before solving. Solve first, rename second.
  • Skipping the check. It takes one line and catches a sign error every time.
  • Restricting the domain and then forgetting to say so in the answer.

2.6The rules of logarithms

Not started

Learn it on Khan AcademyVideo The logarithm rules · Intro to logarithm properties (1 of 2)Video The rule that solves equations · Using the logarithmic power ruleVideo The change of base formula for logarithmsArticle The rules, written out · Intro to logarithm propertiesPractise it on Khan AcademyExercise Expanding and condensing · Use the properties of logarithmsExercise Evaluate logarithms: change of base rule
The three rules
logb(MN) = logbM + logbNlogbMN = logbM − logbNlogb(Mn) = n logbM
The one that does not exist
There is no rule for log(M + N). A sum inside a logarithm does not come apart. Nothing you do to it will shorten it.
The ones that follow from the definition
logb1 = 0logbb = 1logb(bx) = xblogbx = x
  1. To expand, factor the argument first. A product becomes a sum, a quotient a difference.
  2. Then bring any exponent down as a coefficient. That is the power rule doing the work.
  3. To condense, run the three rules backwards. Power rule first, then the product rule, then the quotient rule. In that order.
  4. The power rule is the one that solves equations. It brings the unknown down out of the exponent, where you can reach it.
  5. Change the base when the calculator has not got it. logbM = ln Mln b
  6. Check the argument is positive before applying any of it. A logarithm of zero or of a negative number does not exist.
Expand log(x2yz)
  1. = log(x2y) − log z
    Quotient rule first.
  2. = log(x2) + log y − log z
    Then the product rule on the top.
  3. = 2 log x + log y − log z
    Then the power rule on the first term.
Solve 3x = 50
  1. ln(3x) = ln 50
    Take the log of both sides.
  2. x ln 3 = ln 50
    The power rule brings x down.
  3. x = ln 50ln 3 ≈ 3.56
    Divide, then use the calculator once.
  • Watch out
  • Inventing a rule for log(M + N). There is not one.
  • log(M)log(N) is not log(MN). The product rule turns a product into a sum.
  • Applying a rule before checking the argument is positive.
