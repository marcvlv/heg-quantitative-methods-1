Adding and multiplying functions

Not started

Khan AcademyPractise: Quotients and sums of fractions · Add & subtract rational expressionsPractise: Products of functions · Multiply binomialsKhan has no lesson on f + g, f − g and fg as such. These two are the same algebra on expressions, which is the closest it gets.
The five
(f + g)(x) = f(x) + g(x)(fg)(x) = f(x)g(x)and the same idea for the difference, the quotient, and a constant times a function.
  1. Do the operation one value at a time. Whatever x is, work out f(x) and g(x), then combine those two numbers.
  2. The result is defined only where both are. Intersect the two domains.
  3. A quotient also needs the bottom to be non-zero. (f/g)(x) needs g(x) ≠ 0.
  4. The combination you will use constantly is profit. P(q) = R(q) − C(q)
  5. Cost usually splits into fixed plus variable. The fixed part is what you pay at q = 0, so it is the y-intercept.

The Rivella Coffee case

The five operations

(f + g)(x) = f(x) + g(x)(f − g)(x) = f(x) − g(x)(fg)(x) = f(x)g(x)(fg)(x) = f(x)g(x)(cf)(x) = c · f(x)
Worked, with f(x) = 3x − 1 and g(x) = x2 + 3x
  1. (f + g)(x) = x2 + 6x − 1
    3x − 1 + x2 + 3x, collected.
  2. (f − g)(x) = −x2 − 1
    3x − 1 − x2 − 3x. The 3x terms cancel.
  3. (fg)(x) = 3x3 + 8x2 − 3x
    (3x − 1)(x2 + 3x), expanded.
  4. (fg)(x) = 3x − 1x2 + 3x
    Undefined where x2 + 3x = 0, so at 0 and −3.
  5. (12f)(x) = 32x − 12
    A constant multiplies every term.

Why it matters: profit

P(q) = R(q) − C(q)
  • Watch out
  • Put the second function in brackets before subtracting, or the signs of its later terms survive when they should not.
  • A quotient is undefined wherever the bottom function is zero, even where the top is perfectly fine.
  • The combination is only defined where both originals are. Intersect the domains.

Reading a graph

Not started

Khan AcademyWatch: Both intercepts · x-intercepts and y-interceptsWatch: Intercepts of a parabola · Interpret a quadratic graphRead: Intercepts of lines review (x-intercepts and y-intercepts)Practise: From the formula · Intercepts from an equationPractise: Intercepts from a graph
  1. The y-intercept is the value at zero. Put x = 0. There is at most one.
  2. The x-intercepts are where the function is zero. Solve f(x) = 0. There may be several, or none.
  3. Plot the intercepts first, then enough points to see the shape.
  4. In a business question the intercepts mean something. The y-intercept is usually a fixed cost. An x-intercept is usually break-even.
  5. A vertical line is not a function. x = 3 is a perfectly good line and has no y to be a function of x.

The method

Worked: y = 2x + 3
  1. y = 0 → 0 = 2x + 3
    Set y to zero for the x-intercept.
  2. x = −32
    One x-intercept.
  3. x = 0 → y = 2(0) + 3 = 3
    Set x to zero for the y-intercept.
A second: x = 3
  1. x = 3
    A vertical line.
  2. no y-intercept
    Because x can never be 0 on this graph.

Break-even is an x-intercept

  • Watch out
  • A zero denominator is not an x-intercept. It is a break in the curve.
  • For a quadratic, a negative discriminant means no x-intercept at all, and that is a complete answer.
  • Only the numerator can make a fraction zero, so solve the numerator and then check the value is allowed.

Composition of functions

Not started

Khan AcademyWatch: What a composite is · Composing functionsWatch: At a number · Evaluating composite functionsRead: The definition · Intro to composing functionsPractise: At a number · Evaluate composite functionsPractise: Building the formula · Find composite functions
Composition
(g ∘ f)(x) = g(f(x))Do f first, then feed its output straight into g. The circle is read right to left.
  1. Work from the inside out. Compute the inner value, then put it into the outer function.
  2. Substitute the whole inner output. Every x in the outer function becomes the entire inner expression, brackets included.
  3. Order matters. f ∘ g is almost never g ∘ f. Check with one number if you doubt it.
  4. For it to exist, the middle value has to be allowed. f(x) must be something g accepts.
  5. The quantity in the middle is real, but the question is not about it. Advertising gives customers, customers give revenue; the question asks revenue from advertising.
The calculation
  1. R(N(x)) = 70(100x) + (100x)220
    Every n becomes 100x, including the one being squared.
  2. = 7000x + 500x
    Because (100x)2 = 10 000x and 10 000x20 = 500x.

The definition

(g ∘ f)(x) = g(f(x))

Two properties

Order matters: f(x) = 2x + 1, g(x) = x2 − 3
  1. (g ∘ f)(x) = (2x + 1)2 − 3 = 4x2 + 4x − 2
    Write the outer function with an empty bracket, then fill it.
  2. (f ∘ g)(x) = 2(x2 − 3) + 1 = 2x2 − 5
    The other order.
  3. at x = 4: 78 against 27
    Same functions, same input, different answers.
  • Watch out
  • (g ∘ f)(x) is not g(x) · f(x). The ring is not a multiplication dot.
  • The whole inner function goes inside the bracket: (2p + 1)2, never 2p2 + 1.
  • Take the domain from the two original functions, not from the tidied-up composite.

Inverses, and when one exists

Not started

Khan AcademyWatch: What an inverse is · Intro to inverse functionsWatch: When one exists · Invertible functionsRead: One-to-one, written out · Intro to invertible functionsPractise: Spotting when there is no inverse · Determine if a function is invertiblePractise: Reading an inverse off a graph · Inverse functions: graphs and tables
Inverse
The function that sends each output back to the input it came from.f(f−1(x)) = f−1(f(x)) = x
One-to-one
Different inputs always give different outputs. No output is ever produced twice.
  1. A function has an inverse exactly when it is one-to-one. That is the whole condition.
  2. On a graph, the horizontal line test decides. A horizontal line may meet the graph at most once. Twice means two inputs share an output, so there is no way back.
  3. Strictly increasing or strictly decreasing is enough. A function that only ever rises, or only ever falls, is one-to-one.
  4. The domain and the range swap. The inverse's inputs are the original's outputs.
  5. The graph of the inverse is the reflection in the line y = x.
  • Watch out
  • An inverse is not a reciprocal. f−1(x) is not 1f(x).
  • A function that repeats an output has no inverse, because there is no way back to which input it came from.
  • Swapping the domain and the range is part of the answer, not an afterthought.
Q(p) = 50 000 000p + 1 − 5 000 000   for 0 ≤ p ≤ 9
The derivation
  1. q = 50 000 000p + 1 − 5 000 000
    Start from the definition.
  2. q + 5 000 000 = 50 000 000p + 1
    Move the constant across.
  3. p + 1 = 50 000 000q + 5 000 000
    Take reciprocals of both sides.
  4. P(q) = 50 000 000q + 5 000 000 − 1
    The price as a function of the quantity.

The definition and the check

f(f−1(x)) = f−1(f(x)) = x

Finding an inverse

Not started

Khan AcademyWatch: Finding one, step by step · Finding inverse functions: linearWatch: Checking it · Verifying inverse functions by compositionRead: The method, written out · Intro to inverse functionsPractise: Finding one · Find inverses of linear functionsPractise: Checking by composition · Verify inverse functions
  1. Write y = f(x).
  2. Solve for x in terms of y. This is the only step that is real work.
  3. Swap the names. x goes back to being the input, so the answer is written as a function of x.
  4. Check by composing both ways. You should get x back each time. This catches almost every slip.
  5. If it is not one-to-one, restrict the domain until it is. f(x) = (x − 1)2 has no inverse until you keep only x ≥ 1.
  6. The linear case is worth knowing by sight. f(x) = ax + b⇒f−1(x) = x − ba
  7. To solve f(x) = k, apply the inverse to both sides. That is what an inverse is for.

Finding one, and when it exists

The general linear case: f(x) = ax + b
  1. g(x) = x − ba
    Undo in reverse order: subtract b, then divide by a.
  2. f(g(x)) = ax − ba + b = x
    Check one way.
  3. g(f(x)) = (ax + b) − ba = x
    And the other. So it is the inverse, and it is linear too.

Using an inverse to solve an equation

  • Watch out
  • f−1(x) is the inverse function, not 1f(x).
  • A function that fails the horizontal line test has no inverse until its domain is restricted.
  • Domain and range swap. If you are asked for the domain of the inverse, look at the range of the original.

The rules of logarithms

Not started

Khan AcademyWatch: The logarithm rules · Intro to logarithm properties (1 of 2)Watch: The rule that solves equations · Using the logarithmic power ruleWatch: The change of base formula for logarithmsRead: The rules, written out · Intro to logarithm propertiesPractise: Expanding and condensing · Use the properties of logarithmsPractise: Evaluate logarithms: change of base rule
The three that exist
log(ab) = log a + log blog ab = log a − log blog(an) = n log a
The one that does not
There is no rule for log(a + b). It does not simplify. Nothing you do turns a sum inside a logarithm into anything shorter.
  1. Expanding: a product becomes a sum, a quotient a difference, a power a coefficient.
  2. Simplifying: the same three rules read right to left.
  3. The power rule is the one that solves equations. It brings the unknown down out of the exponent where you can reach it.
  4. Change the base when the calculator has not got it. logbx = ln xln b
  5. The exponential and the logarithm undo each other. exp(ln u) = uax = exp(x ln a)for a > 0
  6. Check the argument is positive before applying any of it.

Expanding

Writing logarithms in terms of simpler logarithms
  1. ln xzw = ln x − ln(zw)
    Quotient rule first.
  2. = ln x − ln z − ln w
    Then the product rule, and the minus reaches both.
  3. ln x5(x − 2)8 ÷ (x − 3)3 → 13[5 ln x + 8 ln(x − 2) − ln(x − 3)]
    A cube root is a power of one third, so the whole bracket is scaled by it.

Simplifying

Worked examples
  1. ln e3x = 3x
    The two undo each other.
  2. log 1 + log 1000 = 0 + 3 = 3
    1000 = 103.
  3. log7978 = 89
    Because 978 = 78/9.
  4. log32781 = log313 = −1
    3334 = 3−1.
  5. ln e + log 110 = 1 + (−1) = 0
    Both special values.

In summary

exp(ln u) = uln(exp x) = xexp(x) = u ⇔ x = ln uax = exp(x ln a) for a > 0
  • Watch out
  • log(a + b) does not break up. There is no rule for the logarithm of a sum.
  • log alog b is not log(a − b), and (log a)2 is not 2 log a.
  • Isolate the exponential before taking logarithms, and reject any answer that makes an original logarithm take a non-positive input.
