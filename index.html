Show the answers and the reasoning

1. C. Factor the denominator: x2 − 4x + 3 = (x − 1)(x − 3), which vanishes at 1 and 3. D comes from a sign error when factoring. The numerator plays no part in a domain.

2. A. Require 5 − 2x ≥ 0, so 5 ≥ 2x and x ≤ 52. B is the answer you get if you divide by −2 without reversing the inequality.

3. D. A logarithm needs a strictly positive argument, so 2x − 6 > 0 and x > 3. A fails because ln 0 does not exist.

4. B. At x = 2 the condition x ≥ 2 holds, so use the second line: 3(2) − 1 = 5. At x = −1 use the first: (−1)2 = 1. The sum is 6. C is what you get by taking the wrong branch at the boundary, which is the whole point of the question.

5. A. Inside first: f(2) = 5. Then g(5) = 2(5) − 3 = 7. B is (f ∘ g)(2), the other order, which is a different function.

6. D. Write y = 3x − 52, multiply by 2 to get 2y = 3x − 5, add 5, divide by 3: x = 2y + 53. Then swap the letters. B is the reciprocal, not the inverse.

7. B. f(−3) and f(3) are both 5, so the function is not one-to-one and cannot be run backwards: from an output of 5 you cannot tell which input produced it. The other three are strictly increasing on ℝ. Restricting the domain to x ≥ 0 would repair A.

8. C. Ask what power of 3 gives 81. Since 34 = 81, the answer is 4. A is 81 written as 33 confused with 34.

9. D. ln(e5) = 5 because ln and exp undo each other, and log(100) = 2 because log is base 10. So 5 − 2 = 3. A adds instead of subtracting.

10. B. A sum of logarithms is the logarithm of the product, and a difference is the logarithm of the quotient. C is the false rule the document warns about: there is no rule for the logarithm of a sum.

11. A. Take the natural logarithm of both sides: x ln 5 = ln 20, so x = ln 20ln 5 = 2.99571.6094 ≈ 1.861. C is the same fraction upside down. Check it: 51.861 ≈ 20.

12. C. Multipliers compose, they do not cancel: 1.2 × 0.8 = 0.96, a fall of 4%. The 20% fall is taken on the larger figure, which is why the round trip loses money. D is the intuitive wrong answer.

13. B. 4000 × 1.035 = 4000 × 1.159274 ≈ 4637.10. D is simple interest, 4000 × (1 + 0.15), which ignores that each year earns interest on the previous years.

14. D. 3x2 = 12, so x2 = 4 and x = ±2. B forgets to divide by 3 first. C forgets that a square root of a positive number has two signs.

15. C. Δ = (−4)2 − 4(2)(5) = 16 − 40 = −24, which is negative, so there is no solution in ℝ. Do not force a square root of a negative number.

16. A. Note first that x ≠ 1. Cross-multiply: x + 2 = 3(x − 1) = 3x − 3, so 5 = 2x and x = 2.5. That is allowed, since it is not 1. B is the excluded value itself.

17. C. Add the two equations to eliminate y: 3x = 9, so x = 3, and then y = 1. D is the pair written in the wrong order, which the exam will mark wrong.

18. B. −3x > 9. Dividing by −3 reverses the direction: x < −3. C is the answer if you forget to flip, and it is the most common error in the topic.

19. A. A distance of 4 from zero means 2x − 6 = 4 or 2x − 6 = −4, giving x = 5 or x = 1. B keeps only the positive case.

20. D. a = −2 < 0, so the parabola opens downwards and the turning point is a maximum. It sits at x = −122(−2) = 3, and f(3) = −18 + 36 − 7 = 11. A has the right point but the wrong shape; C forgets the −7.

Show the full solutions and the mark scheme

Question 1

(a) Two conditions. The root needs x − 2 ≥ 0, so x ≥ 2. The denominator needs x − 5 ≠ 0, so x ≠ 5. Both must hold at once, so the domain is [2 ; 5[ ∪ ]5 ; +∞[, which is the same set as {x ∈ ℝ : x ≥ 2 and x ≠ 5}.

(b) (g ∘ h)(x) = g(x2 + 2) = 3(x2 + 2) − 1 = 3x2 + 5. And (h ∘ g)(x) = h(3x − 1) = (3x − 1)2 + 2 = 9x2 − 6x + 3. At x = 1: (g ∘ h)(1) = 8 and (h ∘ g)(1) = 6. Two different numbers from the same pair of functions and the same input, so composition is not commutative.

(c) y = 3x − 1 gives x = y + 13, so g−1(x) = x + 13. g is a straight line with a non-zero slope, so it is strictly increasing and therefore one-to-one. h is not: h(−1) = h(1) = 3, so from an output of 3 you cannot recover the input.

(d) x = 0 gives the y-intercept (0, −1). y = 0 gives 3x = 1, so the x-intercept is (13, 0).

Question 2

(a) Divide by 3 first: 2x = 32. Since 32 = 25, x = 5. Taking logarithms also works and earns the same marks: x = ln 32ln 2 = 5.

(b) The domain comes first: x > 0 and x − 3 > 0, so x > 3. Combine the left side with the product rule: ln(x(x − 3)) = ln 10. Both sides are logarithms in the same base, so x(x − 3) = 10, that is x2 − 3x − 10 = 0, which factors as (x − 5)(x + 2) = 0. The candidates are 5 and −2. Only x = 5 survives, because −2 is not greater than 3 and would ask for the logarithm of a negative number. Saying why you reject it is worth a mark.

(c) Losing 12% means multiplying by 0.88 each year, so V(t) = 80 000 × 0.88t. Set 80 000 × 0.88t < 30 000, so 0.88t < 0.375. Take natural logarithms: t ln 0.88 < ln 0.375. Question 3

(a) Let q be the number of boxes sold in a month. C(q) = 14q + 9 000, R(q) = 32q, and P(q) = 32q − (14q + 9 000) = 18q − 9 000, all in CHF a month. The 18 is the contribution margin, what each box adds once its own variable cost is paid.

(b) Break-even is P(q) = 0, so 18q = 9 000 and q = 500 boxes. Revenue there is 32 × 500, that is 16 000 CHF. The shortcut is worth knowing: break-even quantity is fixed costcontribution margin.

(c) P(900) = 18(900) − 9 000 = 16 200 − 9 000, so 7 200 CHF a month.

(d) The new contribution margin is 35 − 14 = 21 CHF, so profit becomes 21 × 780 − 9 000 = 16 380 − 9 000, that is 7 380 CHF. That is 180 CHF a month better, so on these figures the rise is worth making. Say the condition out loud, because it carries a mark: the conclusion depends entirely on the estimate of 780 boxes, and the proposal breaks even against the old profit at 7 200 + 9 00021, that is 772 boxes. Below roughly 772 boxes the price rise loses money.

Question 5

(a) The 90 is the price in CHF per kilogram at which demand falls to zero, the highest price anyone would pay. The −0.5 is the slope: every extra kilogram the firm wants to sell requires the price to drop by 0.50 CHF per kilogram. Units are the mark here.
