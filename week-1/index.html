Linear equations and systems

Not started

Khan AcademyWatch: First order equations · Why we do the same thing to both sidesWatch: Systems, by substitution · Solving systems of equations with substitutionRead: The method, written out · Multi-step equations reviewPractise: First order equations · Equations with variables on both sidesPractise: Systems, by elimination · Systems of equations with elimination
First order
One unknown, first power. ax + b = 0 with a ≠ 0.
A system
Two equations that have to hold at the same time, for the same pair of values.
  1. Clear brackets, then fractions. Multiply every term by the common denominator, the right-hand side included.
  2. Collect the unknown on one side, the numbers on the other.
  3. Divide by the coefficient. ax + b = 0⇒x = −ba
  4. For a system, eliminate. Scale one equation so a letter cancels when you add the two.
  5. Or substitute. Make one equation say x = something, and put that into the other one.
  6. Check the pair in both equations. One equation cannot catch an error.
Three outcomes
One solution. None, when you reach something false. Infinitely many, when you reach something always true. None of the three is a mistake.

First order equations

x = −ba
Worked: 3x + 1 = 5x + 7
  1. 3x + 1 = 5x + 7
    Collect the x terms on one side, the numbers on the other.
  2. −2x = 6
    3x − 5x = −2x and 7 − 1 = 6.
  3. x = −3
    Divide by −2.

Systems of first order equations

The same system, both ways
  1. 2x + y = 18 and −x + 5y = 2
    The system to solve.
  2. −2x + 10y = 4
    Method 1: multiply the second equation by 2, then add it to the first.
  3. 11y = 22, so y = 2 and x = 8
    The x terms cancel.
  4. x = 5y − 2
    Method 2: isolate x in the second equation instead.
  5. 2(5y − 2) + y = 18
    Substitute into the first.
  6. 11y = 22, so y = 2 and x = 8
    The same answer, as it must be.
  • Watch out
  • Multiplying an equation in a system means multiplying its right-hand side too.
  • −(x − 4) = −x + 4. Losing that second sign is the commonest slip here.
  • Check your pair in both equations. One is not enough.

Quadratic equations in business

Not started

Khan AcademyWatch: The formula · The quadratic formulaWatch: What the discriminant tells you · Using the quadratic formula: number of solutionsRead: The discriminant · Discriminant reviewPractise: Using the formula · Quadratic formulaPractise: Reading the discriminant · Number of solutions of quadratic equations
  1. Everything to one side. ax2 + bx + c = 0,a ≠ 0
  2. Read off a, b and c with their signs. The signs are where the marks go.
  3. Work out the discriminant first. Δ = b2 − 4acΔ > 0: two rootsΔ = 0: oneΔ < 0: none in ℝ
  4. Factor if it factors, otherwise use the formula. x = −b ± Δ2a
  5. In a business question, break-even is where revenue meets cost. R(q) = C(q) rearranges to a quadratic you already know how to solve.
  6. Throw away a root the situation forbids. A negative quantity or a negative price is not an answer.
x1 = −b + Δ2ax2 = −b − Δ2a
Worked: 3x2 + 3x − 18 = 0
  1. Δ = 32 − 4(3)(−18) = 225
    Positive, so two solutions.
  2. x = −3 ± 156
    225 = 15.
  3. x = 2 or x = −3
    The two roots.
  4. 3x2 + 3x − 18 = 3(x + 3)(x − 2)
    It also factors directly, which is faster when the numbers are kind.

The application: Berger Tools

The solution
  1. C(q) = 6q + 80 000
    Total cost: variable plus fixed.
  2. R(q) = 10q
    Total revenue: price times quantity.
  3. P(q) = R(q) − C(q) = 4q − 80 000
    Profit is the difference of the two functions.
  4. 60 000 = 4q − 80 000
    Set the profit to the target.
  5. q = 35 000 units
    Which is the answer to the business question, not just to the algebra.
  • Watch out
  • Δ < 0 means no solution in ℝ. Write that; it is a complete answer.
  • In −4ac with c negative the two signs make a plus. Most wrong discriminants come from here.
  • Move everything to one side before reading off a, b and c.

What a function is

Not started

Khan AcademyWatch: What counts as a function · Recognizing functionsWatch: Evaluating a function · Worked example: Evaluating functions from equationWatch: Lines, slope and intercept · Worked examples: slope-intercept introPractise: Evaluating · Evaluate functionsPractise: The vertical line test · Recognize functions from graphsPractise: Reading a line off a graph · Slope-intercept equation from graph
Function
A rule that gives each allowed input exactly one output. That is the whole definition.
f(x)
The output at x. It is not f times x.
Four representations
A formula, a table, a graph, a sentence. The same function, four ways, and you are expected to move between them.
Vertical line test
If a vertical line meets the graph twice, it is not a function: that input would have two outputs.
  1. To evaluate, replace every x by the whole input. Brackets included: f(a + 1) needs (a + 1) everywhere.
  2. Read a table exactly, a graph approximately. A graph gives you the shape and the trend, not the fourth decimal.
  3. Slope is rise over run, and it is the same wherever you measure it. m = ΔyΔx = y2 − y1x2 − x1
  4. To sketch a line, plot two points and join them. The intercepts are usually the two easiest.
  5. A vertical line has no slope. x = k is not a function, and its slope is undefined rather than zero.

The course definition

The worked case: Rivella Coffee

The four representations

Evaluating, and why brackets matter
  1. h(x) = 2
    A constant function: every input gives 2.
  2. h(10) = 2, h(−213) = 2, h(x + 3) = 2
    The third one makes the point.
  3. f(x) = x2 − 3x at x = a + 1
    Replace every x by (a + 1), brackets included.
  4. (a + 1)2 − 3(a + 1) = a2 − a − 2
    Expand afterwards.
  • Watch out
  • f(x) is one number, the output. It is not f times x.
  • f(a + 1) is not f(a) + 1.
  • A vertical line meeting the graph twice means it is not a function: that input would have two outputs.

  • Watch out
  • Slope is ΔyΔx. Subtract the coordinates in the same order top and bottom.
  • x = k is vertical and has undefined slope, which is not slope zero.
  • An unlabelled sketch earns no marks even when the curve is right.

Domain and range

Not started

Khan AcademyWatch: What is the domain of a function?Watch: What is the range of a function?Practise: Finding a domain · Determine the domain of functionsPractise: Reading both off a graph · Domain and range from graph
Domain
Every input the rule accepts.
Range
Every output that actually occurs. Usually smaller than you expect.
  1. Start by assuming every real number is allowed. Then take away what is forbidden.
  2. A denominator may not be zero. Set it to zero, solve, and exclude those values.
  3. An even root may not have a negative underneath. x − 3 needs x ≥ 3.
  4. A logarithm needs a strictly positive argument.
  5. Solve each condition, then keep everything that survives all of them.
  6. Write it whichever way you like. An inequality, a set or an interval. All three are the same answer.
  7. From a graph, read both straight off the axes. The domain is how far the curve reaches left and right, the range how far it reaches up and down.
Worked: f(x) = x ÷ (x − 2)
  1. f(x) = xx − 2
    A quotient, so the denominator is the risk.
  2. x − 2 = 0 → x = 2
    Find where the denominator vanishes.
  3. every real number except 2
    That is the domain.
A second: f(x) = x ÷ (x2 − x − 2)
  1. x2 − x − 2 = 0
    Same method, harder denominator.
  2. (x − 2)(x + 1) = 0
    Factor it.
  3. every real number except 2 and −1
    Two values removed, not one.

When two things can go wrong at once

Three ways to write it, and the range

  • Watch out
  • A root needs ≥ 0; a logarithm needs > 0, strictly.
  • Simplifying first can hide a restriction. Take the domain from the formula as given.
  • Context can shrink a domain the algebra allows: 7.3 employees is not an input.

Six families of function

Not started

Khan AcademyWatch: Parabolic functions · Intro to parabolasWatch: Graphs of absolute value functionsWatch: Graphs of rational functionsPractise: Parabolas introPractise: Case-defined functions · Evaluate piecewise functions
The six families
Constant, linear, quadratic, polynomial, rational, absolute value. Recognising the family from the formula tells you the shape before you draw anything.
  1. Look at the formula, not at the picture. The form is what names the family.
  2. Linear: one x, first power. A straight line.
  3. Quadratic: there is an x². A parabola, opening upwards when a > 0.
  4. Rational: an x in a denominator. So find the domain before anything else.
  5. Absolute value: distance from zero, so never negative. |x| = x if x ≥ 0,−x if x < 0
  6. Case-defined: several rules over several intervals. Graph each piece only over its own interval, and check what happens at the joins.

Absolute value

|x| = x if x ≥ 0,   −x if x < 0

Case-defined functions

Graphed
  1. f(x) = x for 0 ≤ x < 3
    First piece: the line y = x.
  2. f(x) = x − 1 for 3 ≤ x < 5
    Second piece: the same slope, shifted down.
  3. f(x) = 4 for 5 ≤ x < 7
    Third piece: constant.
  • Watch out
  • x2 is a power function and 2x is exponential. The variable is in a different place.
  • A case-defined function is one function, not three. It has one domain and one range.
  • At a boundary, only one case applies. The inequality signs tell you which.

Exponential functions

Not started

Khan AcademyWatch: What makes it exponential · Exponential vs. linear growthWatch: Where e comes from · 𝑒 and compound interestWatch: e as a limit · 𝑒 as a limitPractise: Growth and decay in context · Exponential expressions word problems (numerical)Practise: The two shapes · Graphs of exponential growth
Exponential function
f(x) = bx with b > 0 and b ≠ 1. The variable is in the exponent, and that is what makes it exponential.
Growth or decay
Growth when b > 1, decay when b is between 0 and 1.
  1. Growing by p% each period multiplies by the same number each period. ×(1 + p100) each period
  2. Compound interest is the case you will meet most. S = P(1 + r)nP the principal, r the rate per period, n the number of periods.
  3. Read the period off the question. 8% a month and 8% a year are not the same number.
  4. e is a limit, roughly 2.718. exp(x) and ex are the same thing.
  5. A quantity that multiplies by a fixed factor each step is exponential. One that adds a fixed amount each step is linear. That distinction is most of the exam questions.

Compound interest, which is where it comes from

S = P(1 + r)n
Worked: 10 000 CHF at 2% for three years
  1. S(3) = 10 000 × (1.02)³
    The multiplier is 1.02, not 0.02.
  2. = 10 612 CHF
    Rounded to the franc, to the franc.

The number e

Subscribers growing 8% a month from 500
  1. N(t) = 500 · 1.08t
    Same shape as compound interest.
  2. N(6) = 500 · 1.086
    Six months.
  3. = 793 subscribers
    1.086 ≈ 1.5869.
  • Watch out
  • The multiplier for a rise of r per cent is 1 + r100, not r100.
  • b ≠ 1 is part of the definition: 1x is constant, not exponential.
  • An exponential never reaches zero, so a decay question never answers "it becomes zero".

Logarithmic functions

Not started

Khan AcademyWatch: What a logarithm is · Introduction to logarithmsWatch: The shape of the graph · Graphs of logarithmic functionsRead: The definition, written out · Intro to logarithmsPractise: Converting between the two forms · Relationship between exponentials & logarithmsPractise: Evaluating without a calculator · Evaluate logarithmsPractise: Graphing · Graphs of logarithmic functions
Logarithm
y = logbxif and only ifby = xThe logarithm answers: to what power do I raise the base to get this number?
The two on your calculator
log is base 10. ln is base e.
  1. To convert, ask what power the base is raised to. Reading the statement the other way round is most of the work.
  2. Each undoes the other. logb(bx) = xblogbx = x
  3. Without a calculator, write the argument as a power of the base. log232: 32 is 25, so the answer is 5.
  4. Only a strictly positive argument has a logarithm. Check that before you do anything else.
  5. To solve b to the power x equals k, take the log of both sides. The power rule then brings the x down where you can reach it.
y = logbx   if and only if   by = x
logb(bx) = xblogbx = x

The two special logarithms

Worked, without a calculator
  1. log 100 = 2
    Because 100 = 102.
  2. ln 1 = 0
    Because e0 = 1.
  3. log 0.1 = −1
    Because 0.1 = 10−1.
  4. ln e−1 = −1
    The two undo each other.
  • Watch out
  • log x needs x > 0, strictly. No power of a positive base gives zero or a negative.
  • The graph falls without limit as x approaches 0. It never crosses the vertical axis.
  • log(a + b) does not break up. There is no rule for the logarithm of a sum.
