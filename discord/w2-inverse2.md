## 🎯 What this covers
Finding one, checking it, and using it to solve an equation.

## 🔑 Key takeaways
- Solve y = f(x) for x, then swap the names
- Check it by composing both ways and getting x back
- Restricting the domain can create an inverse that did not exist before
- For f(x) = ax + b the inverse is (x − b)/a
