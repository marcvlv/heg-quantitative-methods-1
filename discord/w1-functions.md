## 🎯 What this covers
The definition, and the four ways the same function gets shown.

## 🔑 Key takeaways
- One input, exactly one output. That is the whole definition
- The same function turns up as a rule, a table, a graph or a sentence
- f(x) is the output at x, not f times x
- A function that always returns the same number is still a function
