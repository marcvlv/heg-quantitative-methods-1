## 🎯 What this covers
What an inverse is, when a function has one, and how to spot it on a graph.

## 🔑 Key takeaways
- An inverse undoes the function: f⁻¹(f(x)) = x
- Only a one-to-one function has one
- On a graph, the horizontal line test decides
- The inverse is the reflection of the function in the line y = x
