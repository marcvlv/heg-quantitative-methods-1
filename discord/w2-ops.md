## 🎯 What this covers
Five ways to build a new function out of two you already have.

## 🔑 Key takeaways
- f + g, f − g, fg, f/g and cf are all done value by value
- The result is defined only where both functions are
- f/g also needs g(x) ≠ 0
- The one you use constantly is profit: P(q) = R(q) − C(q)
